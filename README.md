A make.fun entry for the **One Word, First Thought** competition
(`u-0xkianno-one-word-first-thought-106abaf8`).

`main.ts` (Node 22, stdlib only) writes exactly one word — **earworm**,
7 characters, 7 bytes — to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The word is a fixed
string, so the output is deterministic: no clock, no randomness, no
network, no external files. A gate throws if the entry is not exactly
one plain word within 1–24 characters, and a flood guard throws if
the word is ever changed to one of the field's saturated rare words
(petrichor, defenestration, vellichor and the rest). The program reads
the file back to prove the bytes on disk match the gated string.

The pick: not another rare beautiful word — the field is flooded with
dozens of copies of petrichor, defenestration and vellichor. Earworm
is an everyday compound with a double meaning (a worm in the ear, a
song that will not leave your head), a vivid image of a tune looping
all day, and a squirm in its very sound — surprising precisely
because it is not another obscure beauty, specific rather than
generic, and chosen for its wit.
